# Galaxy Shooters

A classic space shooter game built with JavaScript and jQuery where you control a spaceship and shoot down enemy ships.

## Features

- **Classic Space Shooter Gameplay**: Control your ship and shoot down enemies
- **Smooth Controls**: Use WASD or Arrow keys for movement, Space to shoot
- **Progressive Difficulty**: Enemies get faster and spawn more frequently as you level up
- **Power-ups**: Collect power-ups for bonus points, extra lives, faster shooting, or increased speed
- **Visual Effects**: Explosions, particle effects, and smooth animations
- **Responsive Design**: Works on different screen sizes
- **Score System**: Track your score, lives, and current level

## How to Play

1. **Movement**: Use WASD keys or Arrow keys to move your ship
2. **Shooting**: Press Spacebar to shoot at enemies
3. **Objective**: Destroy enemy ships before they reach the bottom of the screen
4. **Power-ups**: Collect green power-ups for various bonuses
5. **Survival**: Avoid enemy bullets and collisions with enemy ships

## Game Controls

- **W / ↑**: Move up
- **S / ↓**: Move down
- **A / ←**: Move left
- **D / →**: Move right
- **Spacebar**: Shoot

## Scoring System

- **Enemy Destroyed**: +100 points
- **Power-up Collected**: Random bonus (points, extra life, faster shooting, or speed boost)
- **Level Up**: Every 1000 points increases the level and difficulty

## How to Run

1. Simply open `index.html` in your web browser
2. Click "Start Game" to begin
3. The game will start immediately with enemies spawning from the top

## Technical Details

- **Built with**: JavaScript, jQuery, HTML5, CSS3
- **No external dependencies** except jQuery CDN
- **Responsive design** that works on desktop and mobile
- **Smooth 60fps gameplay** using requestAnimationFrame

## Game Features

- **Dynamic Enemy Spawning**: Enemies spawn at random positions
- **Enemy AI**: Enemies shoot back at the player
- **Collision Detection**: Precise hit detection for all game objects
- **Visual Feedback**: Explosions and visual effects for destroyed objects
- **Progressive Difficulty**: Game gets harder as you advance through levels

Enjoy playing Galaxy Shooters!
